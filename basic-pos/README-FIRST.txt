BASIC POS SYSTEM - SIMPLE SETUP

1. Make sure Composer and XAMPP PHP are installed.
2. Extract this ZIP inside C:\xampp\htdocs.
3. Open the extracted basic-pos-github-starter folder.
4. Double-click CREATE-PROJECT.bat.
5. Wait for the browser to open at http://localhost:8080/.
6. Keep the black Command Prompt window open while using the website.

The finished GitHub-ready project will be created beside this folder:

    C:\xampp\htdocs\basic-pos-system

Upload the CONTENTS of basic-pos-system to GitHub.

The website pages are:

    http://localhost:8080/
    http://localhost:8080/about
    http://localhost:8080/customers
    http://localhost:8080/users
